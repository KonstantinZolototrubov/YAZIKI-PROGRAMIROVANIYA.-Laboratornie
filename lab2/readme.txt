ПРОГНОЗЫ ДЛЯ 3 ЗАДАНИЯ

Выражение        Прогноз вручную     Результат Python
2 + 3 * 4        14                  14
(2 + 3) * 4      20                  20
17 // 5          3                   3
17 % 5           2                   2
-7 // 2          -4                  -4

Объяснение различий:
В большинстве языков -7 / 2 даёт -3 (округление к нулю).
В Python // — это деление с округлением ВНИЗ (floor), поэтому -7 // 2 = -4.
Оператор % возвращает остаток так, чтобы выполнялось: a = (a // b) * b + (a % b).
Для -7: -7 = (-4) * 2 + 1, поэтому -7 % 2 = 1.

Сдача и защита

1. Отличие / от //:
   - / — обычное деление, всегда возвращает float: 7 / 2 = 3.5.
   - // — целочисленное деление с округлением вниз (floor): 7 // 2 = 3, -7 // 2 = -4.

2. Смысл остатка:
   Оператор % возвращает остаток от целочисленного деления.
   Пример: 17 % 5 = 2, потому что 17 = 3 * 5 + 2.
   Остаток удобен для перевода секунд в минуты/часы и для подсчёта неполных единиц.

3. Почему форматирование не устраняет неточность float:
   Форматирование "{:.2f}" меняет только отображение числа, но не его внутреннее двоичное представление.
   Например, 0.1 + 0.2 внутри Python равно 0.30000000000000004.
   Если вывести это с двумя знаками, получится 0.30, но ошибка останется внутри.
   Для денег надёжнее хранить копейки в целых числах или использовать Decimal.
