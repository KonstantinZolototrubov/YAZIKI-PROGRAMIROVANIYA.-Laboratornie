Объяснения для защиты

1. Разница между возвратом (return) и выводом (print):
`print()` просто отображает значение на экране, но не сохраняет его в программе для дальнейшего использования.
`return` возвращает результат из функции в точку вызова. Это позволяет сохранить результат в переменную, передать его в другую функцию или использовать в расчетах.

2. Локальная переменная и параметр:
*Параметр* — это переменная, указанная в скобках при объявлении функции (например, `number` в `sum_digits`). Она служит для приема данных извне.
Локальная переменная** создается внутри функции (например, `total = 0` в `sum_digits` или `n = abs(number)`). Она существует только пока выполняется функция и недоступна снаружи.

3. Демонстрация теста, обнаруживающего ошибку:
Допустим, мы намеренно ошиблись в функции `sum_digits` и забыли взять модуль:
```python
def sum_digits(number):
    n = number  # Ошибка! Забыли abs()
    total = 0
    while n > 0:
        total += n % 10
        n = n // 10
    return total
