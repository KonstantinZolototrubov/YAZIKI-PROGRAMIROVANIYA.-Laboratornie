Отличие append() от присваивания по индексу:
append(x) добавляет элемент x в КОНЕЦ списка, увеличивая его длину на 1.
Присваивание list[i] = x заменяет УЖЕ СУЩЕСТВУЮЩИЙ элемент по индексу i. Если индекса i нет (он больше длины списка), возникнет ошибка IndexError. Append безопаснее, когда мы заранее не знаем итоговую длину списка.

Отличие sorted() от sort():
sorted(list) создает и возвращает НОВЫЙ отсортированный список, при этом исходный list остается без изменений.
list.sort() сортирует исходный список НА МЕСТЕ (in-place), изменяя его, и возвращает None. 
В variant.py используется sorted(), чтобы получить отсортированную копию, не ломая исходный порядок элементов в result.
