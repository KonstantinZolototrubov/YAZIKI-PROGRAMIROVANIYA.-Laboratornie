Неизменяемость строк:

Строки в Python неизменяемы (immutable). 
Нельзя изменить отдельный символ:
s[0] = "X" вызовет ошибку. 
Любая «модификация» (lower(), replace(), strip())
создаёт НОВУЮ строку, а старая остаётся прежней. 
Поэтому мы сохраняем результат в новую переменную.

Отличие слова от подстроки:

Слово — это логическая единица текста, обычно отделённая пробелами (её даёт split()).
Подстрока — это любая непрерывная часть строки, найденная по позиции (срез, find()).
Например, в "армия" подстрока "рми" существует, но это не отдельное слово.

Почему правила обработки пунктуации нужно задать до написания программы:

От этого зависит алгоритм. Если пунктуацию игнорировать (как в палиндроме
для пробелов), нужно её отбрасывать. Если сравнивать как есть (как в palindrome.py
для пунктуации) — нужно её сохранять. Если удалять с краёв слов (как в variant.py
через strip), нужно точно знать, какие символы удалять. Без чётких правилпрограмма может дать разный результат на одном и том же тексте.
